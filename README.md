# MiniDb

サンプル用の簡易データベースです。実行ファイル1つで動き、ランタイムのインストールは不要です（Windows / macOS / Linux）。
テーブルは `data/テーブル名.csv`（UTF-8）として保存されます。

- **データの編集** … 管理画面（GUI）で行います
- **データの出力** … コマンドで実行すると、結果が標準出力に出ます（他システムとの連携用）

## 管理画面（GUI）

実行ファイルを**ダブルクリック**すると、ブラウザで管理画面が開きます（コマンドでは `minidb gui`）。

- テーブルの作成（カラムを指定 / CSVファイルから作成 / CSVテキストを貼り付けて作成）
- セルを直接編集、行・カラムの追加と削除、カラム名の変更 → 「保存」（Ctrl+S）で反映
- CSV/TSV のインポート（追記 / 置き換え）。1行目がカラム名。UTF-8 / Shift_JIS（Excel保存）を自動判別
- **CSVテキストの貼り付けでも取り込み可能**（ファイルのアップロードが禁止されている環境向け）。
  Excel などからコピーした表（タブ区切り）もそのまま貼り付けられます。区切り文字は自動判別
- テーブルごとに、他システムから使うコマンド例を表示（コピー可）

一緒に開く黒い画面（コンソール）を閉じると管理画面は終了します。
管理画面は自分のPCからだけ接続できます（127.0.0.1 で待ち受け、起動ごとの合言葉付き）。

## 出力コマンド

```
minidb select users                               # テーブル全体（CSV）
minidb select users name,age --where dept=開発     # カラムと条件を指定
minidb select users --format json                 # JSONで出力
minidb tables                                     # テーブル一覧
minidb columns users                              # カラム一覧
```

出力例（`minidb select users name,age --where dept=開発`）:

```
name,age
佐藤花子,28
鈴木一郎,45
```

- 標準出力には結果だけを出します。メッセージとエラーは標準エラー出力です。
- 終了コード: `0`=成功 / `1`=入力エラー（存在しないテーブルやカラムなど） / `2`=ファイルエラー
- 出力形式: `--format csv|tsv|json|value`、ヘッダーなしは `--no-header`、件数制限は `--limit N`
- 条件: `--where` に `=` `!=` `>` `<` `>=` `<=` `~`(部分一致)。複数指定で AND。数値同士は数値として比較
- 文字コード: 標準出力は UTF-8（BOMなし）。Shift_JIS が必要なら `--encoding sjis`
- データ保存先: 既定は実行ファイルと同じ場所の `data/`。`--db <フォルダ>` または環境変数 `MINIDB_DIR` で変更可（管理画面でも同じ指定が使えます）

## macOS / Linux での注意

- 初回は実行権限を付けてください: `chmod +x minidb`
- macOS でダウンロードしたファイルがブロックされる場合: `xattr -d com.apple.quarantine minidb`
- ダブルクリックでターミナルが開かない環境では、ターミナルで `./minidb gui` を実行してください

## ビルド（開発者向け）

Go 1.26 以上が必要です（依存ライブラリ golang.org/x/text・x/term の要件）。

```
./build.sh 1.1.0     # dist/ に全OS向けの配布用アーカイブを作成
go build .           # 自分の環境向けだけ作る場合
```
