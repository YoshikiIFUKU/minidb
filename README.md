# SampleDB

サンプル用の簡易データベースです。実行ファイル1つで動き、ランタイムのインストールは不要です（Windows / macOS / Linux）。
テーブルは `data/テーブル名.csv`（UTF-8）として保存されます。

- **データの編集** … 管理画面（ブラウザ）で行います
- **データの出力・追加** … コマンドで実行します（他システムとの連携用。出力は標準出力へ）

## 管理画面

実行ファイルを**ダブルクリック**すると、ブラウザで管理画面が開きます（コマンドでは `SampleDBApp gui`）。

**テーブルの操作**
- 作成（カラムを指定 / CSVファイルから / CSVテキストを貼り付けて）、名前の変更、削除
- CSV/TSV の取り込み（追記 / 置き換え）。1行目がカラム名。UTF-8 / Shift_JIS（Excel保存）を自動判別
- **CSVテキストの貼り付けでも取り込み可能**（ファイルのアップロードが禁止されている環境向け）。
  Excel などからコピーした表（タブ区切り）もそのまま貼り付けられます

**表の編集**
- セルを直接編集。**改行を含む値**も入力できます（セルをダブルクリックすると大きな入力欄で編集）
- 行の追加・削除・**上下の入れ替え**
- カラムの追加・削除・名前の変更・**左右の入れ替え**
- 見出しの ▲▼ で**並び替え**（数値は数値として比較）
- 絞り込み（全カラムを対象に文字を含む行だけ表示）、表示する行数の切り替え
- 「保存」（Ctrl+S）でファイルに反映。「変更を取り消す」で保存前の状態に戻せます

**表示**
- ライト / ダーク / システム（OSの設定に従う）を切り替えられます。選択はブラウザに記憶されます

一緒に開く黒い画面（コンソール）を閉じると管理画面は終了します。
管理画面は自分のPCからだけ接続できます（127.0.0.1 で待ち受け、起動ごとの合言葉付き）。

## 出力コマンド

```
SampleDBApp select users                              # テーブル全体（CSV）
SampleDBApp select users name,age --where dept=開発    # カラムと条件を指定
SampleDBApp select users dept --distinct               # 重複を除いて一意な値だけ
SampleDBApp select users --sort age --desc             # 並び替え（降順）
SampleDBApp select users --format json                 # JSONで出力
SampleDBApp tables                                     # テーブル一覧
SampleDBApp columns users                              # カラム一覧
```

出力例（`SampleDBApp select users name,age --where dept=開発`）:

```
name,age
佐藤花子,28
鈴木一郎,45
```

- 標準出力には結果だけを出します。メッセージとエラーは標準エラー出力です。
- 終了コード: `0`=成功 / `1`=入力エラー（存在しないテーブルやカラムなど） / `2`=ファイルエラー
- 出力形式: `--format csv|tsv|json|value`、ヘッダーなしは `--no-header`、件数制限は `--limit N`
- 条件: `--where` に `=` `!=` `>` `<` `>=` `<=` `~`(部分一致)。複数指定で AND。数値同士は数値として比較
- 並び替え: `--sort カラム`（`--desc` で降順）。処理順は 絞り込み → 並び替え → `--distinct` → `--limit`
- 一意化: `--distinct` は**出力するカラムの組み合わせ**が重複する行をまとめます
- 文字コード: 標準出力は UTF-8（BOMなし）、改行は LF。Shift_JIS が必要なら `--encoding sjis`
- データ保存先: 既定は実行ファイルと同じ場所の `data/`。`--db <フォルダ>` または環境変数 `SAMPLEDB_DIR` で変更可

## 追加コマンド（insert / import）

他システムからコマンドで行を追加できます。

**1行だけ追加する（insert）**

```
SampleDBApp insert users id=6 name=伊藤 dept=営業
```

- `カラム=値` を並べます。指定しなかったカラムは空になります
- 値に空白を含む場合は `"name=伊藤 太郎"` のように全体を `"` で囲みます

**複数行を追加する（import）**

1行目にカラム名、2行目以降にデータを書いた CSV / TSV を渡します。

```
SampleDBApp import users add_rows.csv
type add_rows.csv | SampleDBApp import users -
```

add_rows.csv の例:

```
id,name,dept
7,渡辺,開発
8,"小林, 花子",総務
9,加藤,"営業
第2課"
```

複数行を追加するときの仕様:

| 項目 | 動作 |
|---|---|
| 1件でも誤りがある場合 | **1行も追加しません**（全件成功か全件失敗）。エラーには行番号が出ます |
| カラムの順序 | 1行目のカラム名で対応づけるので、テーブルと順序が違っても構いません |
| 一部のカラムだけ | 可能です。書かなかったカラムは空になります |
| 列数が1行目と合わない行 | エラーになります（値にカンマや改行を含むときは `"` で囲みます） |
| 存在しないカラム | エラーになります。追加したい場合は `--add-columns` |
| 存在しないテーブル | エラーになります。作りたい場合は `--create` |
| 追記 / 置き換え | 既定は追記。`--mode replace` でテーブルの内容をファイルの内容に置き換えます（カラムもファイルに合わせます） |
| 区切り文字 | 既定は自動判別（1行目にタブがあればタブ区切り）。`--sep comma` / `--sep tab` で固定 |
| 文字コード | UTF-8 / Shift_JIS を自動判別します |
| 値の中の改行 | `"` で囲めば保持されます |
| 同時に実行した場合 | 書き込みは1つずつ順番に行われるので、行が消えることはありません（最大10秒待ちます） |
| 管理画面で開いている間に追加した場合 | 管理画面での保存時に「他で更新されています」と表示され、開き直すと追加された行が反映されます（上書きで消えることはありません） |

- 成功すると終了コード `0`。メッセージは標準エラー出力に出て、標準出力には何も出ません
- **PowerShell で標準入力に渡す場合**: Windows PowerShell 5.1 は既定で日本語を `?` に変えて渡してしまいます。
  ファイル名を直接指定する（`SampleDBApp import users add_rows.csv`）か、先に `$OutputEncoding = [Text.Encoding]::UTF8` を実行してください

## 改行を含む値を扱うとき

セルに改行を入れられます。保存時は CSV の規則どおり `"` で囲まれ、値の中の改行はそのまま保持されます。
出力するときは形式によって扱いが変わるので、受け取る側に合わせて選んでください。

- `--format csv` / `tsv` … 値は `"` で囲まれ、改行はそのまま出ます（1レコードが複数行になります）。
  CSV として解析する側なら正しく読めますが、「1行＝1レコード」として読む処理だと崩れます
- `--format json` … 改行は `\n` に変換されるので、1行のJSONとして安全に渡せます
- `--format value` … 値をタブで並べるだけなので、改行を含む値には向きません

改行を含むデータを他システムに渡すときは `--format json` が安全です。

## macOS / Linux での注意

- コマンド名は大文字・小文字を区別します。`SampleDBApp` と入力してください（Windows では区別しません）
- 初回は実行権限を付けてください: `chmod +x SampleDBApp`
- macOS でダウンロードしたファイルがブロックされる場合: `xattr -d com.apple.quarantine SampleDBApp`
- ダブルクリックでターミナルが開かない環境では、ターミナルで `./SampleDBApp gui` を実行してください

## ビルド（開発者向け）

Go 1.26 以上が必要です（依存ライブラリ golang.org/x/text・x/term の要件）。

```
./build.sh 2.0.0     # dist/ に全OS向けの配布用アーカイブを作成
go build .           # 自分の環境向けだけ作る場合
```
