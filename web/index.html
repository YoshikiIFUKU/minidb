    新しいテーブル

    1行目がカラム名、2行目以降がデータになります。ファイルから作成するとき、テーブル名が空ならファイル名を使います。

    左の一覧からテーブルを選ぶか、新しいテーブルを作成してください。
    ● 未保存の変更があります

    他のシステムから使うコマンド（結果が標準出力に出ます）

    --format json / tsv で形式を変更、--no-header で見出し行なし、--sort カラム（--desc で降順）、 --distinct で重複を除く、--encoding sjis で Shift_JIS 出力。

    1行目にカラム名、2行目以降にデータを入力してください。Excel などからコピーした表もそのまま貼り付けられます。

    改行を含む値を入力できます。Enter で改行、保存は下のボタンから（表の「保存」を押すまでファイルには書き込まれません）。
